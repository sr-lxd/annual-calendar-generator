# 万年历生日与节日配置生成器

这是一个 Windows 桌面小工具，用于按年份生成生日与节日配置。程序读取本地 Excel 名单中的姓名和身份证号码，从号码中提取月、日，再与 `festivals.ini` 中的公历、农历节日合并，最后写出 `config.ini`。

当前版本生成的是日期与事件配置文件，不负责绘制或导出整张年历。程序使用 Tkinter 提供窗口界面。

## 功能

- 选择 1900—2100 年中的一个年份。
- 从 Excel 名单中读取姓名和身份证号码，支持 15 位和 18 位号码格式。
- 按月、日提取生日信息，并与公历节日和农历节日合并。
- 计算母亲节、父亲节、感恩节、除夕，以及代码中定义的教育活动周和考试日期。
- 将全年日期和对应事件写入 `config.ini`，同一天的节日与生日会合并显示。
- `config.sample.ini` 提供一份使用虚构姓名和日期的输出示例。
- 通过 `festivals.ini` 自定义公历和农历节日。

## 运行环境

- Windows 10 或 Windows 11
- Python 3.10 或更高版本
- Python 自带的 Tkinter（Windows 安装 Python 时请保留 Tcl/Tk 组件）

## 安装和启动

在项目目录打开 PowerShell：

```powershell
py -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
pip install -r requirements.txt
python ".\sofia万年历生成器v0.18.py"
```

## 准备输入名单

程序在当前工作目录查找 `身份证号.xlsx`。如果文件不存在，程序会创建一个只有表头的空白工作簿。请在其中准备以下两列：

| 姓名 | 身份证号 |
| --- | --- |
| 示例人员甲 | SAMPLE-ID-001 |
| 示例人员乙 | SAMPLE-ID-002 |

上表中的值只说明列名和格式，不是可用于生成生日的有效号码。运行时请用经授权的真实数据替换示例值。身份证号码属于敏感个人信息，建议在 Excel 中把该列设为文本，防止长数字被自动改写。

运行程序后选择年份并点击“生成 config.ini”。生成的 `config.ini` 会包含姓名和生日日期；若同名文件已存在，程序会先将旧文件改名为 `config_1.ini`、`config_2.ini` 等，再生成新文件。

`config.sample.ini` 只用于查看文件结构，不会被程序读取，也不会覆盖运行时生成的 `config.ini`。其中“示例人员”与日期均为虚构值。

## 节日配置

项目中的 `festivals.ini` 是不含个人或机构信息的示例配置。它有两个区段：

```ini
[solar_festivals]
1,1 = 元旦

[lunar_festivals]
1,1 = 春节
```

日期键使用“月,日”格式。修改或增加节日后重新运行程序，生成的配置会采用更新后的名称。公历节日使用公历日期，农历节日使用农历日期。

## 隐私说明

- 身份证号码和姓名只由本机程序读取；程序没有联网上传功能。
- `身份证号.xlsx` 含敏感个人信息，`config.ini` 及 `config_*.ini` 含姓名和生日。请把这些文件留在本机，不要上传到 GitHub 或发给无关人员。
- 仓库的 `.gitignore` 会忽略 Excel 工作簿和生成的生日配置，只保留虚构内容的 `config.sample.ini`。提交前仍应检查 `git status` 和暂存文件清单。
- 仓库中的 `festivals.ini` 仅含通用示例节日，不包含个人生日、学校名称或内部活动安排。
